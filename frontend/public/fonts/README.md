# Instrument Sans

Self-hosted variable font from [Google Fonts](https://github.com/google/fonts/tree/809e4d8b8d7e9364a914909bb777679606c178b8/ofl/instrumentsans), pinned at `809e4d8b8d7e9364a914909bb777679606c178b8`.

The original font is unchanged. `OFL-InstrumentSans.txt` contains the SIL Open Font License. No browser request to a font provider is required.
