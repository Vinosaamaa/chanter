# Account exports and coordinated data lifecycle

Adds private bounded exports, browser download authorization and source-owned terminal recovery. Search and notification fence delayed delivery; community preserves terminal-bound dependent Course/channel IDs before graph erasure. Media deletion waits for settled object writes, including legacy migration PUTs. Auth journal allocation is atomic only with its own coordinator/outbox state; other sources apply independently. Accepted moderation now includes permanent canonical deletion checks in its live account/source authority. Archived scope import verifies ordered IDs/counts/digests and atomically reconciles an already-applied community terminal fence, including a graph absent at the restored backup. A separate verified-restore union preserves historical child relationships without changing the current archive; notification cleanup uses it before completing recovery. Public coordinated deletion, remaining source cleanup and final operational proof remain in progress.

Search and agent also consume both verified scope kinds. Agent terminal writes share a fixed lock order with ingestion, native evidence, answers and reservations; resource deletion erases derived content and temporary exports without refunding unknown provider usage. Focused rollback, replay, stale-write and reservation/settlement race tests pass. Retained attribution/accounting records keep account and server receipts pending until their remaining cleanup is implemented.

Media now applies the same terminal authority before publication and access, queues cleanup in bounded pages through its existing worker, and preserves uncertain upload reservations. Recovery startup preserves an unknown storage namespace. Focused media rollback, stale scanner, scope import and storage-safety tests pass; physical deletion and downstream confirmation remain pending.
