# Account exports and coordinated data lifecycle

Adds private bounded exports, browser download authorization and source-owned terminal recovery. Search and notification fence delayed delivery; community preserves terminal-bound dependent Course/channel IDs before graph erasure. Media deletion waits for settled object writes, including legacy migration PUTs. Auth journal allocation is atomic only with its own coordinator/outbox state; other sources apply independently. Accepted moderation now includes permanent canonical deletion checks in its live account/source authority. Archived scope import verifies ordered IDs/counts/digests and atomically reconciles an already-applied community terminal fence, including a graph absent at the restored backup. A separate verified-restore union preserves historical child relationships without changing the current archive; notification cleanup uses it before completing recovery. Public coordinated deletion, remaining source cleanup and final operational proof remain in progress.

Search and agent also consume both verified scope kinds. Agent terminal writes share a fixed lock order with ingestion, native evidence, answers and reservations; resource deletion erases derived content and temporary exports without refunding unknown provider usage. Focused rollback, replay, stale-write and reservation/settlement race tests pass. Retained attribution/accounting records keep account and server receipts pending until their remaining cleanup is implemented.

Media now applies the same terminal authority before publication and access, queues cleanup in bounded pages through its existing worker, and preserves uncertain upload reservations. Recovery startup preserves an unknown storage namespace. Focused media rollback, stale scanner, scope import and storage-safety tests pass; physical deletion and downstream confirmation remain pending.

Message source cleanup and permanent write checks now pass focused rollback, replay, recovered-scope and concurrent deletion tests. The existing social pair lock remains after the terminal lock, and delayed accepted-answer delivery acknowledges terminal targets without sending notifications. Downstream source IDs remain available for pending reconciliation.

The normal account coordinator now commits canonical authority, revocation and durable commands together, with explicit confirmation, ownership release and bounded read-only post-logout progress. Focused rollback, session, expiry, replay and gateway-route tests pass. Lifecycle expiry beans use the same recovery-mode guard as the recovery lane. Resource-derived accepted-answer delivery and remaining normal source coordination stay open review requirements.

Source-owned server/resource deletion now enters the canonical auth journal through fixed durable requests; pending access closure precedes independent source cleanup. Focused common/auth/community/media tests cover local rollback, retries, request scope and worker behavior. Normal scope relay, final progress UX, delayed accepted-answer reconciliation and cross-service hosted proof remain open.

Exact answer retraction now joins payload erasure to ordered message and notification reconciliation. Permanent per-answer receipt identity survives a newer question cursor, so reordered delivery cannot strand cleanup. Later valid answers and human outcomes remain intact. Legacy shared notification rows retain navigation/read state with neutral, content-free text. Focused migrated-source tests prove queued/claimed/reordered delivery, rollback of completion receipts, live visibility and one-time repair after outbox payload erasure. Full hosted union remains pending. The account/export UI contract is recorded for #339; server/resource progress stays in this owning lane.

Ordinary deleted-server scope delivery now advances one immutable page per existing outbox command and retains the five dependent READY dispositions. Final import/receipt rollback, empty scope, page order and duplicate delivery have real-store regressions. No new scheduler or retry queue is introduced; isolated recovery keeps using its archive relay. The unshipped canonical fixture calls real owning deletion paths and returns their committed journal/scope pages, with a focused auth preparation test. Full native three-target proof remains pending.

Requester-bound server/resource progress is now documented and tested for the #339 frontend integration. Auth terminal cleanup removes ordinary credentials and profile values, fences later writes, and reports PRESERVED for its UUID tombstone and fixed moderation records. Existing operator authority serialization precedes user rows during cleanup, avoiding the inverse order of privileged moderation actions. Thirty-three focused auth checks cover original account/OAuth/moderation behavior, terminal races, rollback, preserved appeals and source completion gated by external acknowledgement. Other source payload disposition and full hosted union remain unfinished.

Community writes now hold terminal authority through their graph/content transaction, and cleanup retains shared courses under the actual current owner. Original resource requesters can recover a lost deletion response after graph removal. Independent review of that checkpoint found no blocker; downstream completion remained pending.

Account-authored content delivery now uses bounded pages on the existing outbox. Permanent search/notification markers and exact-command receipts prevent old claimed events from recreating erased payloads. Source payload retirement and destination acknowledgements have transactional rollback/reorder tests. Existing human notification metadata survives neutral preview cleanup. This remains a draft: explicit producer final/zero-content dispositions, remaining source retention, actual PostgreSQL/browser/recovery proof and final operational gates are still required. Hosted preview fixture corrections preserve permanent 410 denial and use explicit answer columns; they do not change production behavior.

Shared question notification payloads now become neutral ID-only updates at the writer boundary. Cleanup neutralizes bounded older payload pages through the deletion cutoff while retaining their pending/claimed delivery and later human updates. Regressions cover a later pending human notification delivered after cleanup, 65 retained payloads, claimed retry, and source/recipient rollback. Full common and agent tests pass after isolating the terminal fixture database and awaiting actual bounded worker completion in the source-timeout regression.

Focused common/community/message/notification tests pass, including pagination, stale claim completion, rollback, and failed coordinator-receipt rollback.
