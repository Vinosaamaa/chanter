# Account exports and coordinated data lifecycle

Adds private bounded exports, browser download authorization and source-owned terminal recovery. Search and notification fence delayed delivery; community preserves terminal-bound dependent Course/channel IDs before graph erasure. Media deletion waits for settled object writes, including legacy migration PUTs. Auth journal allocation is atomic only with its own coordinator/outbox state; other sources apply independently. Public coordinated deletion, remaining source cleanup, accepted moderation integration and final operational proof remain in progress.
