# Protected native companion pairing and study integration

Connect the unsigned native developer companion through live browser-session checks, explicit terminal pairing and study approval, signed single-use capabilities, authorized evidence release, and validated source-quotation acceptance. Shared reservations retain unknown usage; web API/source options remain independent. Tested source packages carry checksums and free provenance, without claiming OS trust or eligible-account proof.
